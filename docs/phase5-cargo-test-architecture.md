# Phase 5: Cargo Test Architecture for C Test Files

## Overview

Replace the dual testing system (inline C in Rust tests + separate invoke test) with a unified approach where `cargo test` directly reads and validates C test files from the colocated `tests/` directories.

## Goals

1. **Eliminate DRY violation**: Stop maintaining duplicate test cases (inline C strings vs .c files)
2. **Unified testing**: `cargo test` becomes the primary test runner
3. **Leverage existing test files**: Use the 2,710 C test files already merged and colocated
4. **Per-rule validation**: Each test file validates ONLY its associated rule
5. **Fast iteration**: Maintain cargo test speed and IDE integration benefits
6. **Granular test output**: Each .c file generates its own test (e.g., `test_arr00_fail_testcases_array_parameters`)
7. **Zero hardcoding**: Auto-discover rules and tests by walking directory structure

## Architecture

### Test Execution Flow

```
Build-time (build.rs):
  ↓
  Walk src/rules/cert_c/CATEGORY/RULE-ID/ directories
    → Find directories with tests/fail/ or tests/pass/
    → For each .c file, generate a #[test] function
    → Write generated test code to OUT_DIR/integration_tests.rs
  ↓
Compile-time:
  ↓
  Include generated tests: include!(concat!(env!("OUT_DIR"), "/integration_tests.rs"))
  ↓
Runtime (cargo test):
  ↓
  test_arr00_c_fail_testcases_array_parameters()
    → Load ARR00-C from RuleRegistry
    → Parse tests/fail/testcases_array_parameters.c
    → Run rule.check()
    → Assert: violations NOT empty
  ↓
  test_arr00_c_pass_wiki_compliant_1()
    → Load ARR00-C from RuleRegistry
    → Parse tests/pass/wiki_compliant_1.c
    → Run rule.check()
    → Assert: violations IS empty
  ↓
  ... (repeat for each .c file across all 23 rules)
```

### Test File Organization

```
src/rules/cert_c/tests/
└── integration.rs                # Includes generated tests from build.rs
                                  # No per-rule files needed!

target/
└── debug/
    └── build/
        └── sqc-*/
            └── out/
                └── integration_tests.rs   # Generated at build-time
                                          # Contains ~2,710 individual #[test] functions
```

**Key insight**: Build script generates individual test functions for each .c file, providing granular output without manual maintenance.

### Phase 5.2: Extend build.rs with test generation

```rust
// build.rs (add to existing file)

fn generate_integration_tests() {
    use std::io::Write;

    let out_dir = std::env::var("OUT_DIR").unwrap();
    let dest_path = std::path::Path::new(&out_dir).join("integration_tests.rs");
    let mut f = std::fs::File::create(&dest_path).unwrap();

    // Write file header
    writeln!(f, "// Auto-generated integration tests").unwrap();
    writeln!(f, "// DO NOT EDIT - Generated by build.rs\n").unwrap();
    writeln!(f, "use crate::parser::CParser;").unwrap();
    writeln!(f, "use crate::rules::{{CertRule, RuleRegistry}};").unwrap();
    writeln!(f, "use std::path::Path;\n").unwrap();

    let cert_c_dir = std::path::PathBuf::from("src/rules/cert_c");

    // Walk through CATEGORY directories
    for category_entry in std::fs::read_dir(&cert_c_dir).unwrap() {
        let category_entry = category_entry.unwrap();
        let category_path = category_entry.path();

        if !category_path.is_dir() {
            continue;
        }

        let category_name = category_path.file_name().unwrap().to_str().unwrap();

        // Skip special directories
        if category_name == "tests" || category_name == "utils" || category_name.starts_with('.') {
            continue;
        }

        // Walk through RULE-ID directories
        for rule_entry in std::fs::read_dir(&category_path).unwrap() {
            let rule_entry = rule_entry.unwrap();
            let rule_path = rule_entry.path();

            if !rule_path.is_dir() {
                continue;
            }

            let rule_id = rule_path.file_name().unwrap().to_str().unwrap();
            let tests_dir = rule_path.join("tests");

            if !tests_dir.exists() {
                continue;
            }

            // Generate tests for fail/ directory
            let fail_dir = tests_dir.join("fail");
            if fail_dir.exists() {
                for test_file in std::fs::read_dir(&fail_dir).unwrap() {
                    let test_file = test_file.unwrap();
                    let test_path = test_file.path();

                    if test_path.extension().map_or(false, |e| e == "c") {
                        generate_test_function(
                            &mut f,
                            rule_id,
                            category_name,
                            &test_path,
                            "fail"
                        );
                    }
                }
            }

            // Generate tests for pass/ directory
            let pass_dir = tests_dir.join("pass");
            if pass_dir.exists() {
                for test_file in std::fs::read_dir(&pass_dir).unwrap() {
                    let test_file = test_file.unwrap();
                    let test_path = test_file.path();

                    if test_path.extension().map_or(false, |e| e == "c") {
                        generate_test_function(
                            &mut f,
                            rule_id,
                            category_name,
                            &test_path,
                            "pass"
                        );
                    }
                }
            }
        }
    }

    println!("cargo:rerun-if-changed=src/rules/cert_c");
}

fn generate_test_function(
    f: &mut std::fs::File,
    rule_id: &str,
    category: &str,
    test_path: &std::path::Path,
    test_type: &str  // "fail" or "pass"
) {
    use std::io::Write;

    // Convert rule_id to snake_case for function name
    let rule_snake = rule_id.to_lowercase().replace('-', "_");

    // Get test file name without extension
    let test_file_stem = test_path.file_stem().unwrap().to_str().unwrap();
    let test_name_safe = test_file_stem.replace('-', "_").replace('.', "_");

    // Generate test function name: test_arr00_c_fail_wiki_noncompliant_1
    let test_fn_name = format!("test_{}_{}_{}",  rule_snake, test_type, test_name_safe);

    // Get relative path from project root
    let relative_path = format!("src/rules/cert_c/{}/{}/tests/{}/{}",
        category, rule_id, test_type, test_path.file_name().unwrap().to_str().unwrap());

    writeln!(f, "#[test]").unwrap();
    writeln!(f, "fn {}() {{", test_fn_name).unwrap();
    writeln!(f, "    let registry = RuleRegistry::new();").unwrap();
    writeln!(f, "    let rule = registry.get_rule(\"{}\").expect(\"Rule {} not found in registry\");",
        rule_id, rule_id).unwrap();
    writeln!(f, "    ").unwrap();
    writeln!(f, "    let test_path = Path::new(env!(\"CARGO_MANIFEST_DIR\")).join(\"{}\");",
        relative_path).unwrap();
    writeln!(f, "    let source = std::fs::read_to_string(&test_path)").unwrap();
    writeln!(f, "        .unwrap_or_else(|e| panic!(\"Failed to read {{:?}}: {{}}\", test_path, e));").unwrap();
    writeln!(f, "    ").unwrap();
    writeln!(f, "    let mut parser = CParser::new().expect(\"Failed to create parser\");").unwrap();
    writeln!(f, "    let tree = parser.parse_source(&source)").unwrap();
    writeln!(f, "        .unwrap_or_else(|e| panic!(\"Failed to parse {{:?}}: {{}}\", test_path, e));").unwrap();
    writeln!(f, "    ").unwrap();
    writeln!(f, "    let violations = rule.check(&tree.root_node(), &source);").unwrap();
    writeln!(f, "    ").unwrap();

    if test_type == "fail" {
        writeln!(f, "    assert!(").unwrap();
        writeln!(f, "        !violations.is_empty(),").unwrap();
        writeln!(f, "        \"[{}] Expected violation in {{:?}} but found none\",", rule_id).unwrap();
        writeln!(f, "        test_path.file_name().unwrap()").unwrap();
        writeln!(f, "    );").unwrap();
    } else {
        writeln!(f, "    assert!(").unwrap();
        writeln!(f, "        violations.is_empty(),").unwrap();
        writeln!(f, "        \"[{}] Unexpected violation in {{:?}}: {{}}\",", rule_id).unwrap();
        writeln!(f, "        test_path.file_name().unwrap(),").unwrap();
        writeln!(f, "        violations.first().map(|v| &v.message).unwrap_or(&String::from(\"unknown\"))").unwrap();
        writeln!(f, "    );").unwrap();
    }

    writeln!(f, "}}").unwrap();
    writeln!(f).unwrap();
}

// Call this in main()
fn main() {
    // Existing Windows resource compilation
    #[cfg(target_os = "windows")]
    {
        let mut res = winres::WindowsResource::new();
        res.set_icon("icon.ico");
        res.compile().unwrap();
    }

    // Existing rules-all.toml generation
    generate_rules_all_toml();

    // NEW: Generate integration tests
    generate_integration_tests();
}
```

## Performance Considerations

### Build Time
- **First build**: ~2-5 seconds to generate test functions
- **Incremental**: Only regenerates if src/rules/cert_c/ changes
- **Test count**: ~2,710 individual test functions

### Test Execution Time
- **Parallel**: cargo test runs tests concurrently across CPU cores
- **Parser reuse**: Each test creates its own parser (could optimize later)
- **Expected runtime**: 30-120 seconds for full suite
- **Single rule**: `cargo test arr30_c` runs only that rule's tests (~5-10s)

## Benefits

### Zero Hardcoding
- No magic paths in test code
- No rule-specific test files to maintain
- Add new test: Drop .c file in directory → rebuild → test appears

### Granular Output
- Each .c file is its own test function
- Easy to identify which specific test failed
- Can run single test: `cargo test test_arr30_c_fail_basic_overrun`
- Can run rule: `cargo test arr30_c`
- Can run fail tests: `cargo test _fail_`

### Developer Experience
- **Fast feedback**: `cargo test` runs everything
- **IDE integration**: Run/debug individual tests in IDE
- **Test filtering**: `cargo test arr30` runs all ARR30-C tests
- **Parallel execution**: Automatic via cargo test

### Maintenance
- **Single source of truth**: C test files only
- **Auto-discovery**: Tests generated automatically
- **No duplication**: No inline C strings to sync
- **Scales easily**: Adding 1,000 more tests requires no code changes
