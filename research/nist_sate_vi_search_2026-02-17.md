### Summary

- SATE VI was a security-focused bug finding evaluation exercise carried out from 2018 to 2023.
- Existing bugs were extracted from bug tracker reports and the CVE/NVD database; additional bugs were injected using automated tools and manual analysis.
- Results showed significant variability across tool effectiveness depending on test cases, bug classes, and bug complexity.
- SATE VI concludes static analysis is a useful technique to find real security bugs in large code bases.
- Included a Mobile Track Report (2023) and Ockham Sound Analysis Criteria track (tools with no FPs or FNs).
- SATE VI workshop was September 2019.
- No 2024 or 2025 SATE results found. Most recent reports are from 2023.
