### Key Quantitative Findings

- **False positive rates ranged from 6.5% to 63%** across evaluated tools (from one study).
- **Best-performing tool had 5-7% false alarm rate** for common CWEs (Tool C in an anonymized study).
- One study used 21,000+ test cases for 22 C/C++ CWEs and 7,500+ test cases for 19 Java CWEs.
- Different tools often report different vulnerabilities (complementary coverage).
- Static analysis provides more coverage than penetration testing, but higher FP rates.
