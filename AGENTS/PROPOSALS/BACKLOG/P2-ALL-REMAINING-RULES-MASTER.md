## Already STAGED (18 High-Priority Rules - NOT in distribution)

These rules are already complete and in STAGED:
1. API01-C - Avoid laying out strings in memory directly before sensitive data
2. API02-C - Functions that read or write to or from an array should take an argument
3. ERR33-C - Detect and handle standard library errors
4. EXP15-C - Do not place a semicolon on the same line as an if, for, or while statement
5. FIO34-C - Distinguish between characters read from a file and EOF or WEOF
6. FIO37-C - Do not assume that fgets() or fgetws() returns a nonempty string
7. INT18-C - Evaluate integer expressions in a larger size before comparing
8. INT32-C - Ensure that operations on signed integers do not result in overflow
9. POS30-C - Use the readlink() function properly
10. POS36-C - Observe correct revocation order while relinquishing privileges
11. POS37-C - Ensure that privilege relinquishment is successful
12. POS54-C - Detect and handle POSIX library errors
13. PRE09-C - Do not replace secure functions with deprecated or obsolescent functions
14. SIG30-C - Call only asynchronous-safe functions within signal handlers
15. SIG31-C - Do not access shared objects in signal handlers
16. STR38-C - Do not confuse narrow and wide character strings and functions
17. WIN01-C - Do not forcibly terminate execution
18. WIN02-C - Restrict privileges when spawning child processes

## Workflow

### For Team Members
1. Navigate to your assigned directory: `AGENTS/PROPOSALS/ACTIVE/{YOUR_NAME}/`
2. Pick any proposal from your list
3. Follow the implementation steps in the proposal
4. Mark proposal as STAGED when complete (move to STAGED directory)
5. Update this master document with progress

### Commands
```bash
# View your assignments
ls AGENTS/PROPOSALS/ACTIVE/{YOUR_NAME}/

# Work on a specific rule
./scripts/claude_mode_impl_rule_utils.sh {RULE-ID}

# Run tests for a rule
cargo test {RULE-ID}

# Build and regenerate tests
cargo build
```
