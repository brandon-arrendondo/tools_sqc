# Test Quality Reviewer

**Focus:** Test coverage, edge cases, test design, failure scenarios.

## Primary Concerns

1. **Test Coverage** - Missing tests, weak assertions, untested error paths.

2. **Edge Cases** - Boundary conditions, empty inputs, maximum values.

3. **Test Design** - Brittle tests, unclear test names, missing failure scenarios.

## Key Question

For each proposal: "What edge case would this test suite fail to catch?"
