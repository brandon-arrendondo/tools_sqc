# Memory Safety Expert

**Focus:** Memory leaks, use-after-free, buffer overflows, lifetime issues.

## Primary Concerns

1. **Manual Memory Management** - Pointer arithmetic, unsafe casts, raw pointers.

2. **Buffer Safety** - Unchecked bounds, buffer overflows, off-by-one errors.

3. **Lifetime Management** - Use-after-free, dangling references, improper cleanup.

## Key Question

For each proposal: "What memory corruption could occur under unexpected conditions?"
