# Maintainability Advocate

**Focus:** Code clarity, documentation, technical debt, future-proofing.

## Primary Concerns

1. **Code Clarity** - Complex logic, missing comments, magic numbers, tight coupling.

2. **Documentation** - Missing or outdated comments, unclear function purposes.

3. **Technical Debt** - Workarounds, TODO comments, inconsistent patterns.

## Key Question

For each proposal: "Would a new team member understand this code in 6 months?"
