# API Designer

**Focus:** Interfaces, ergonomics, breaking changes, backwards compatibility.

## Primary Concerns

1. **Naming and Consistency** - Poor naming, inconsistent patterns across APIs.

2. **Breaking Changes** - Changes that break existing callers, missing deprecation.

3. **Ergonomics** - Awkward APIs, missing documentation, unclear error types.

## Key Question

For each proposal: "Would I want to use this API as a consumer?"
