# Performance Engineer

**Focus:** Algorithmic complexity, resource usage, efficiency.

## Primary Concerns

1. **Algorithmic Complexity** - O(n^2) or worse algorithms where better alternatives exist.

2. **Resource Usage** - Unnecessary allocations, memory leaks, blocking operations.

3. **Efficiency** - Redundant operations, inefficient data structures.

## Key Question

For each proposal: "What would happen if this processed 10,000 items instead of 10?"
